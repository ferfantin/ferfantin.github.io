About
Game UI Designer in Guildford, UK

Hail, mortal, nice to meet you!

My name is Fernanda, and I am an UI Designer working in the games industry!

I have a bachelor's degree in fashion design, but being so passionate about games made me start pursuing a career that allowed me to create interactive experiences.

I develop mockups alongside Game Designers, create high-fidelity assets, and help Programmers figure out the best way to make all the planned work happen. I also create game logos, non-UI 2D art and font creation on some occasions, which you can check in this portfolio!

This is an interactive space I created to share my work and, by extension, to be a portfolio piece by itself. So please, make yourself at home!
